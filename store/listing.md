## 개인정보 보호 관행 탭

**단일 목적 설명**
> 엔트리(playentry.org) 작품 만들기 화면의 모양 편집기에 캐릭터 애니메이션용 편집 도구(레이어·클리핑, 뼈대 변형, 부드러운 붓·지우개·사각 펜, 영역 채우기, 투명도, 캔버스 크기·무한 배경, 어니언스킨, 스프라이트 시트 나누기, 중심 맞추기, 모양 이름 붙이기, 픽셀 아트)를 더합니다.

**권한 사유** — 요청 권한은 사이트 접근 하나뿐입니다(`content_scripts`의 `https://playentry.org/ws/*`).
> 엔트리 작품 만들기 화면(playentry.org/ws/)에서 모양 편집기에 도구를 붙이기 위해서만 실행됩니다. 다른 사이트에서는 실행되지 않으며, 그 밖의 권한(탭·저장소·네트워크 요청 가로채기 등)은 요청하지 않습니다.

**원격 코드 사용**: 아니요. 모든 코드는 패키지 안에 있습니다.
- `rig.js`
- `vendor/` 라이브러리 9개(IK.ts, Warp.js, delaunator, gl-matrix, 1eurofilter, d3-array, d3-contour, ag-psd, bresenham-zingl). npm 공식 배포본 원본 그대로이고, 일부는 전역으로 잡히게(또는 엔트리 페이지 로더와 섞이지 않게) 앞뒤 감싸는 줄만 더했습니다.

**데이터 사용**
- 사실: 개발자에게 보내는 데이터는 없습니다(분석·광고·외부 서버 없음).
- 사실: 사용자가 변환이나 저장을 실행하면 그 그림을 엔트리 자기 서버(`playentry.org/rest/picture/*`)로 올립니다. 엔트리 저장과 같은 요청입니다.
- 사실(1.2): 사용자가 `.ent`·오브젝트 파일을 내려받으면 엔트리가 보내는 요청(`playentry.org/rest/project/download`, `/rest/object/download`)에 레이어 정보를 덧붙이고, `.ent`를 불러오거나 라이브러리 그림에 픽셀 아트를 켜면 레이어·그림 파일을 엔트리 서버(`/rest/picture/*`)에 다시 올립니다. 보내는 곳은 여전히 엔트리 서버뿐이고 새 권한은 없습니다(1.1.0 manifest와 비교 — 버전·라이브러리 2개만 다름).
- 미확정: 이 업로드를 "사용자 데이터 수집"으로 체크해야 하는지는 공식 FAQ에 딱 맞는 사례가 없어 확정하지 못했습니다.
- 정한 것: 수집 항목은 "웹사이트 콘텐츠"만 체크합니다(사용자가 만든 그림을 엔트리 서버로 보냄 — 적게 신고해 반려되는 것보다 넓게 신고). 인증 체크박스 3개는 모두 체크합니다.
