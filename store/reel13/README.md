# 1.3 홍보 APNG 다시 만들기

결과: `../promo_reel13_apng.png` (640×360, 15초, 1초 12.5장, 128색, 933,560바이트 — 엔트리 노팁 그림 한도 1MB 안).
장면: 제목 → 그라데이션 도구(엔트리봇 옷에 직선·원형·단계 4) → 레이어 필터(흐림·외곽선·흑백·색 반전) → 레이어 ≡ 끌기(몸 뒤 팔이 앞으로)와 묶음 뼈대 하나 → 끝 카드.
엔트리봇은 1.0 영상의 기본 엔트리봇 그대로 쓰고 조각만 나눈다(사용자: 직접 그린 사람 모양 말고 기본 엔트리봇).

1. `python build.py` — `../promo_reel.svg`(1.0 영상)에서 엔트리봇 두 자세를 꺼내고, 팔 묶음(조각 21·22·23)·팔 뺀 나머지·옷(조각 18) 칠을 바꿀 수 있는 엔트리봇을 만들어 `reel13.html`을 만든다. 조각 순서는 실제 엔트리 새 작품 엔트리봇과 같다(조각 33개, 옷 = 18번 #009ff9 — 실제 엔트리에서 옷에 그라데이션을 끌면 옷 조각만 바뀜 확인).
2. `node cdp_render.js reel13.html full 1280 720 "t => window.renderAt(t)" "0:14.92:0.08"` — 창 없는 크롬으로 187장 찍기.
3. `python assemble.py full ../promo_reel13_apng.png 80 128` — 640×360으로 줄이고 공통 색표로 APNG.

색표 함정: 96색이면 매끈한 그라데이션이 띠로 끊겨 "단계"와 구별이 안 됐다 → 그라데이션 색 사다리를 고정 색에 넣고 128색. 흑백 장면 회색이 갈회색에 붙어 다리가 갈색으로 보였다 → 무채색 고정. 작은 회색 글자가 주황빛 → 글자색과 바탕 사이 중간색 고정. 장면을 바꿔 1MB를 넘으면 색 수부터 줄인다.
