# 개인정보 처리방침

이 확장 프로그램은 엔트리(playentry.org) 작품 만들기 화면의 모양 편집기에 도구를 더하는 비공식 확장입니다.

- **개발자가 모으는 정보는 없습니다.**
  - 이름·이메일·계정·방문 기록·사용 통계를 수집하지 않습니다.
  - 분석 도구, 광고, 외부 서버를 쓰지 않습니다.
- **그림은 브라우저 안에서 처리합니다.** 뼈대 변형, 겹쳐 보기, 시트 나누기, 중심 맞추기 계산은 사용자의 브라우저에서 이루어집니다.
- **엔트리 서버로 올리는 것:** 사용자가 변환·저장 같은 동작을 실행하면, 만든 모양 그림을 엔트리 자기 서버(`playentry.org`)로 올립니다. 엔트리의 모양 저장과 같은 요청입니다. 이 그림은 엔트리의 [이용약관](https://playentry.org/terms/entry)과 [개인정보 처리방침](https://playentry.org/terms/privacy)에 따라 다뤄집니다.
- **제3자에게 넘기지 않습니다.** 엔트리 외의 다른 곳으로 보내는 데이터는 없습니다.

## Privacy Policy (English)

This unofficial extension adds editing tools to the costume editor of Entry (playentry.org).

- **No data collection by the developer.** It does not collect personal information, browsing history, or usage analytics. It does not use analytics, ads, or any external server.
- **Local processing.** Bone deformation, onion skin, sprite-sheet slicing and centering run in your browser.
- **Uploads to Entry only.** When you run a convert or save action, the resulting costume images are uploaded to Entry's own server (playentry.org) through the same request Entry uses to save costumes. They are handled under Entry's terms and privacy policy.
- **No third parties.** Nothing is sent anywhere other than playentry.org.
